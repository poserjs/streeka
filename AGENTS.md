# Repository Guidance

- Keep project communication in English.
- Prefer the `app/` directory for new pages and layouts.
- Add reusable UI pieces to `components/`, shared helpers to `lib/`, shared types to `types/`, and metadata files to `data/`.
- Before finishing work, run the build, test suite, the TypeScript formatting check, and the linter (or note if they are not configured or cannot run).
- Use these commands when available: `npm run build`, `npm run test`, `npm run format:check`, and `npm run lint`.
